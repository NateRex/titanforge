# Sample Application

This module contains a sample application built from the other libraries.

For instructions on how to build and run the application, please refer to the [parent README](../../README.md).

## Controls

| Key(s) | Action |
| --- | --- |
| WASD | Move |
| Mouse| Look |
| Scroll | Zoom |
| 1 | Toggle shadows |
| 2 | Toggle between point and directional lighting. Point light is enabled by default. |
| Escape | Exit |
